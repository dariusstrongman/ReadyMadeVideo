# Full Audiovisual Editor

This initiative upgrades Stromation from rough montage generation to complete,
explainable postproduction for one controlled category: vertical 9:16 fitness
videos, 15-60 seconds, using real uploaded footage.

Implementation follows seven focused milestones. A later milestone may consume an
earlier contract, but it must not silently change or overwrite the evidence that
contract recorded.

1. [Creative Treatment and capture report](MILESTONE-1.md)
2. [Deterministic picture editor](MILESTONE-2.md)
3. [Music and sound supervisor](MILESTONE-3.md)
4. [Licensed audio rendering](MILESTONE-4.md)
5. [Motion graphics, captions, and color finishing](MILESTONE-5.md)
6. Specialized critics and tournament selection
7. Immutable Project One replay and three-way comparison

Project One's existing outputs remain baseline evidence. No file under a local
Project One artifact directory belongs in Git.

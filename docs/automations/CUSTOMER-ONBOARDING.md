# Customer Onboarding Checklist

Per new install, in order. Nothing activates until every box in its section is checked.

## Commercial
- [ ] Signed agreement + 50% setup invoice paid
- [ ] Scope document: which workflows, which integrations, what is out of scope
- [ ] Third-party cost estimate acknowledged in writing

## Access + compliance
- [ ] Integration access granted (phone provider, forms, calendar, CRM), least privilege
- [ ] A2P 10DLC brand + campaign registration submitted on day one (2-3 week lead time)
- [ ] Message templates approved by the customer in writing
- [ ] Escalation contacts named with hours + phone/email
- [ ] Quiet-hours and business-hours policy recorded in tenant config

## Build + test
- [ ] W-004 hub live first (suppression + error alerts)
- [ ] Workflows imported inactive; credentials in n8n storage; tenant config set
- [ ] Full test matrix passed with safe data (TEST-PLAN.md); customer walkthrough done
- [ ] Team trained on handoffs (takes under an hour)

## Launch
- [ ] Acceptance sign-off; remaining 50% setup invoiced
- [ ] Workflows activated one at a time; manual fallback confirmed
- [ ] 24-hour and 7-day reviews scheduled; weekly report enabled
- [ ] Baseline metrics recorded (missed calls, response time, leads, bookings)
